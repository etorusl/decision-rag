# H100: inference и обучение

Для **бенчмаркинга уже готовых моделей** основной путь — локальный vLLM. Обучение не требуется.

```bash
git clone git@github.com:etorusl/decision-rag.git
cd decision-rag
bash scripts/setup_vllm_h100.sh
bash scripts/benchmark_h100.sh multidoc2dial 100
bash scripts/benchmark_h100.sh conditionalqa all
```

Скрипт сравнивает BM25, vLLM embeddings, vLLM embeddings + reranker и два варианта
DecisionRAG на готовой Qwen3. Серверами localhost управляет сам скрипт; на одной H100
embedding/reranker получают по 40% VRAM, затем отдельный Qwen3 server — 85%.
Нужны Linux, Python 3.12 и driver с поддержкой CUDA 12.8.

[Полная инструкция vLLM](vllm.md): подключение к уже запущенным серверам, model revisions,
prefix cache, sampled GPU memory, полные наборы и абляции. Готовые checkpoints не обучаются.

## Обучение собственной scoring-head — отдельный путь

Для этого используется другое окружение `.venv`, PyTorch 2.7.1 и Transformers 4.57.1:

```bash
bash scripts/setup_h100.sh
source .venv/bin/activate
python scripts/h100_preflight.py --json-output results/h100-preflight.json
bash scripts/train_h100.sh multidoc2dial smoke
bash scripts/train_h100.sh multidoc2dial full
```

Не смешивайте `.venv` и `.venv-vllm`: vLLM 0.11.2 требует PyTorch 2.9.0.
Training-скрипт обучает head + LoRA на Qwen3-Base и оценивает custom checkpoint через
`--backend head`. Это специальная архитектура, отдельная от inference готовых моделей vLLM.

`smoke`: первые 500 training queries, два head-only шага и 10 LoRA updates, затем 20 evaluation
queries. `full`: все training queries, 200 head-only шагов и одна эпоха LoRA r64/alpha128.
Monitoring split отделяется по целым диалогам MD2D или training pages CQA. Dev/test labels
не участвуют в обучении. Starting checkpoint — Qwen3-8B-Base, не general-trained judge из статьи.

[Подробности модели и обучения](local-models.md). Optimizer-state resume не реализован;
periodic checkpoints пригодны для inference. Для короткого контекста создайте training records
с `--max-tokens 8000 --max-candidates 64` и обучайте с
`--max-context-tokens 8192 --max-packed-tokens 16384`; это отдельная конфигурация эксперимента.
